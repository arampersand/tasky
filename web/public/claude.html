Claude Code

Your Claude Code sessions on Tasky

One card per session: working, waiting for you, done. When Claude asks permission, answer with the knob.

  1. Plug Tasky into your computer

    With the USB cable, on the computer where Claude Code runs (Tasky 3.0 or newer). Only the first time: after that it also works over Wi-Fi. Close any page that is using Tasky, like the setup page: only one app can hold its USB port.

  2. Paste this in Terminal

    claude plugin marketplace add arampersand/tasky && claude plugin install tasky@tasky
    Or from inside Claude Code
    /plugin marketplace add arampersand/tasky
    /plugin install tasky@tasky

  3. Start Claude Code

    Open (or restart) Claude Code. Tasky shows a Ready card on the Agents screen. Each session gets its own card; turn the knob to go through them.

Approving from the knob

When Claude asks to run a command or edit a file, Tasky jumps to that card and the light breathes. Turn to pick Allow, Deny or Allow edits, press to answer. Hold the knob to answer in the terminal instead.

Something not working?

In Claude Code, run /tasky:status. It checks Python, the USB port, the firmware and the hooks, and says what to fix.

What you need

macOS or Linux with Python 3 (on a Mac: xcode-select --install if it's missing). Windows isn't supported yet.

Unplugged, on battery?

Yes, with Tasky 3.1 or newer. Plug Tasky in once (step 1) and the plugin pairs with it. After that it works over Wi-Fi when Tasky and your computer are on the same network.

Without the plugin

curl -fsSL https://tasky-flash.vercel.app/agents/install.sh | sh adds the same hooks to ~/.claude/settings.json. Use one or the other, not both. How it works →

Claude Code

Tus sesiones de Claude Code en Tasky

Una tarjeta por sesión: trabajando, esperándote, lista. Cuando Claude pide permiso, respondes con la perilla.

  1. Conecta Tasky a tu computadora

    Con el cable USB, en la compu donde corre Claude Code (Tasky 3.0 o más nuevo). Solo la primera vez: después también funciona por Wi-Fi. Cierra cualquier página que esté usando a Tasky, como la de configuración: solo una app puede usar su puerto USB.

  2. Pega esto en la Terminal

    claude plugin marketplace add arampersand/tasky && claude plugin install tasky@tasky
    O desde Claude Code
    /plugin marketplace add arampersand/tasky
    /plugin install tasky@tasky

  3. Abre Claude Code

    Ábrelo (o reinícialo). Tasky muestra una tarjeta Ready en la pantalla Agents. Cada sesión tiene su tarjeta; gira la perilla para recorrerlas.

Aprobar con la perilla

Cuando Claude pide correr un comando o editar un archivo, Tasky salta a esa tarjeta y la luz respira. Gira para elegir Allow, Deny o Allow edits y presiona para responder. Mantén presionada la perilla para responder en la terminal.

¿Algo no funciona?

En Claude Code corre /tasky:status. Revisa Python, el puerto USB, el firmware y los hooks, y te dice qué arreglar.

Qué necesitas

macOS o Linux con Python 3 (en Mac: xcode-select --install si no lo tienes). Windows todavía no.

¿Desconectado, con batería?

Sí, con Tasky 3.1 o más nuevo. Conéctalo una vez (paso 1) y el plugin se empareja. Después funciona por Wi-Fi cuando Tasky y tu compu están en la misma red.

Sin el plugin

curl -fsSL https://tasky-flash.vercel.app/agents/install.sh | sh agrega los mismos hooks a ~/.claude/settings.json. Usa uno u otro, no los dos. Cómo funciona →
