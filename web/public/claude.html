Install Set up

Claude Code

Your Claude Code sessions on Tasky

Tasky shows one card for each Claude Code session: working, waiting for you, or done. When Claude asks for permission, you answer with the knob.

  1. Plug Tasky into your computer

    Use the USB cable. Plug it into the computer where you use Claude Code. You need Tasky 3.0 or newer. You only need the cable the first time. After that, it also works over Wi-Fi (Tasky 3.1 or newer). First, close any other page that is using Tasky, like the setup page. Only one app can use Tasky's USB connection at a time.

  2. Paste this in the Terminal app and press Enter

    claude plugin marketplace add arampersand/tasky && claude plugin install tasky@tasky
    Or type these inside Claude Code
    /plugin marketplace add arampersand/tasky
    /plugin install tasky@tasky

  3. Start Claude Code

    Open Claude Code, or restart it if it was already open. Tasky shows a Ready card on the Agents screen. Each session gets its own card. Turn the knob to see them all.

Answering with the knob

When Claude wants to run a command or change a file, Tasky jumps to that card and the light breathes. Turn the knob to pick Allow, Deny or Allow edits. Press to answer. To answer on your computer instead, hold the knob.

Something not working?

In Claude Code, type /tasky:status. It checks your setup and tells you what to fix.

What you need

A Mac or Linux computer with Python 3. On a Mac, if Python is missing, run xcode-select --install in Terminal. Windows doesn't work yet.

Unplugged, on battery?

Yes, with Tasky 3.1 or newer. Plug Tasky in once (step 1) so the plugin can pair with it. After that it works over Wi-Fi, as long as Tasky and your computer are on the same network.

Without the plugin

For advanced users: curl -fsSL https://tasky-flash.vercel.app/agents/install.sh | sh adds the same setup to your Claude Code settings file, ~/.claude/settings.json. Use this or the plugin, not both. How it works →

Claude Code

Tus sesiones de Claude Code en Tasky

Tasky muestra una tarjeta por cada sesión de Claude Code: trabajando, esperándote o lista. Cuando Claude te pide permiso, respondes con la perilla.

  1. Conecta Tasky a tu computadora

    Usa el cable USB. Conéctalo a la computadora donde usas Claude Code. Necesitas Tasky 3.0 o más nuevo. El cable solo hace falta la primera vez. Después también funciona por Wi-Fi (Tasky 3.1 o más nuevo). Antes, cierra cualquier otra página que esté usando a Tasky, como la de configuración. Solo una app a la vez puede usar la conexión USB de Tasky.

  2. Pega esto en la app Terminal y presiona Enter

    claude plugin marketplace add arampersand/tasky && claude plugin install tasky@tasky
    O escribe esto dentro de Claude Code
    /plugin marketplace add arampersand/tasky
    /plugin install tasky@tasky

  3. Abre Claude Code

    Abre Claude Code, o reinícialo si ya estaba abierto. Tasky muestra una tarjeta Ready en la pantalla Agents. Cada sesión tiene su propia tarjeta. Gira la perilla para verlas todas.

Responder con la perilla

Cuando Claude quiere correr un comando o cambiar un archivo, Tasky salta a esa tarjeta y la luz respira. Gira la perilla para elegir Allow (permitir), Deny (rechazar) o Allow edits (permitir cambios). Presiona para responder. Si prefieres responder en tu computadora, mantén presionada la perilla.

¿Algo no funciona?

En Claude Code, escribe /tasky:status. Revisa tu configuración y te dice qué arreglar.

Qué necesitas

Una Mac o una computadora con Linux, con Python 3. En Mac, si no tienes Python, corre xcode-select --install en la Terminal. Windows todavía no funciona.

¿Desconectado, con batería?

Sí, con Tasky 3.1 o más nuevo. Conéctalo una vez (paso 1) para que el plugin se empareje con él. Después funciona por Wi-Fi, siempre que Tasky y tu computadora estén en la misma red.

Sin el plugin
