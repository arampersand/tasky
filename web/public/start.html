Tasky quick start

A knob, one button, your day at a glance.

Controls

Turn the knob: move, change a value Press: choose, start / pause focus · hold: more options MODE: next screen · twice: back · hold: rest screen

Set up in 2 minutes

  1. Plug Tasky into a computer (Chrome or Edge).
  2. Open tasky-flash.vercel.app → Set up.
  3. Wi-Fi, calendar, tasks, GitHub, city. Every step is optional.

Phone only? On Tasky: Settings → More → Setup (QR), scan, follow the page.

Every day

  • Home: time, weather, what's next, your tasks.
  • Press on Home to focus; the light means "don't disturb".
  • Hold on Home: quick settings.
  • Settings → More → Screens: pick and order your screens.

Claude Code

In Claude Code, with Tasky plugged in:

/plugin marketplace add arampersand/tasky
/plugin install tasky@tasky

Allow or deny Claude's requests with the knob. Trouble? /tasky:status

Tasky: inicio rápido

Una perilla, un botón y tu día de un vistazo.

Controles

Gira la perilla: moverte, cambiar un valor Presiona: elegir, iniciar / pausar el foco · mantén: más opciones MODE: siguiente pantalla · dos veces: regresar · mantén: reposo

Configúralo en 2 minutos

  1. Conecta el Tasky a una computadora (Chrome o Edge).
  2. Abre tasky-flash.vercel.app → Set up.
  3. Wi-Fi, calendario, tareas, GitHub, ciudad. Todo es opcional.

¿Solo celular? En el Tasky: Settings → More → Setup (QR), escanea y sigue la página.

Todos los días

  • Home: hora, clima, lo siguiente y tus tareas.
  • Presiona en Home para enfocarte; la luz dice "no molestar".
  • Mantén en Home: ajustes rápidos.
  • Settings → More → Screens: elige y ordena tus pantallas.

/plugin marketplace add arampersand/tasky

Permite o rechaza lo que pide Claude con la perilla. ¿Problemas? /tasky:status
