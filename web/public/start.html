Tasky quick start

A knob, one button and your day at a glance.

Controls

Turn the knob: move around, change a value Press: choose, start or pause focus · Hold: more options MODE: next screen · press twice: go back · hold: rest screen

Set up in 2 minutes

  1. Plug Tasky into a computer. Use Chrome or Edge.
  2. Go to tasky-flash.vercel.app and click Set up.
  3. Add your Wi-Fi, calendar, tasks and city. You can skip any step.

Only have a phone? On Tasky, open Settings → More → Setup (QR). Scan the code and follow the page.

Every day

  • Home: date, weather, clock, today's focus and one task.
  • Press the knob on Home to focus. The light tells others “don't disturb”.
  • Hold the knob on Home: quick settings.
  • Settings → More → Screens: choose your screens and their order.

Claude Code

Plug Tasky in. Then type these in Claude Code:

/plugin marketplace add arampersand/tasky
/plugin install tasky@tasky

Say yes or no to Claude's requests with the knob. Not working? Type /tasky:status

Tasky: inicio rápido

Una perilla, un botón y tu día de un vistazo.

Controles

Gira la perilla: moverte por el menú, cambiar un valor Presiona: elegir, iniciar o pausar el foco · Mantén: más opciones MODE: siguiente pantalla · dos veces: regresar · mantén: pantalla de descanso

Configúralo en 2 minutos

  1. Conecta tu Tasky a una computadora. Usa Chrome o Edge.
  2. Entra a tasky-flash.vercel.app y haz clic en Set up.
  3. Agrega tu Wi-Fi, calendario, tareas y ciudad. Puedes saltarte cualquier paso.

¿Solo tienes celular? En tu Tasky, abre Settings → More → Setup (QR). Escanea el código y sigue la página.

Todos los días

  • Home: fecha, clima, reloj, tu foco de hoy y una tarea.
  • Presiona la perilla en Home para enfocarte. La luz les dice a los demás “no molestar”.
  • Mantén presionada la perilla en Home: ajustes rápidos.
  • Settings → More → Screens: elige tus pantallas y su orden.

Claude Code

Conecta tu Tasky. Luego escribe esto en Claude Code:

/plugin marketplace add arampersand/tasky
/plugin install tasky@tasky

Acepta o rechaza lo que pide Claude con la perilla. ¿No funciona? Escribe /tasky:status
