# UX Walkthrough (Source of Truth)

Boot:
- Typewriter animation escribe "Tasky"
- Entra directo a pantalla QR
- Texto: "Scan to Start"

Navigation Cycle:
QR → Timer → Tasks → Streak → Clock → Settings → loop

QR Screen:
- Pantalla primaria
- Texto claro: "Scan to Start"
- No decoraciones innecesarias

Timer:
- Short click: Start / Pause
- Long press: Reset
- Ring progress counter-clockwise

Tasks:
- Rotate: navegar
- Short click: toggle done
- Long press: abrir overlay de detalle
- Empty state: "Scan QR code to create tasks"

Streak:
- Rotate: mover cursor
- Click: entrar/salir de edit mode
- Visual feedback claro

Settings:
- Lista corta
- Theme toggle al final
- Animaciones staggered al entrar
