# Tasky 3.0 — one firmware, ready for anyone

**Goal:** one Tasky firmware that someone who has never seen it can flash, set up and enjoy in five minutes (ROADMAP Phase 1 exit criteria), with the computer-companion features for people who code with Claude Code.

**Builds on:** 2.12 (released) and the 2.13 plan (`2026-10-16-v2.13-polish-and-easy-setup.md`), which becomes 3.0's first half.

---

## 1. One firmware (merge Tasky + Tasky for Agents)

- Size today: C6 Agents 1.919 MB; adding the AI and Notion modules ≈ +21 KB; 2.13 UI ≈ +25 KB → ≈ 1.965 MB of the 2.03 MB slot. Fits; keep a 40 KB margin rule.
- Remove the `TASKY_EDITION_AGENTS` split: Agents, Controls, Bluetooth and the companion protocol are always compiled in. Two envs remain (`xiao_c3`, `xiao_c6`); the web flasher loses the edition picker.
- **Bluetooth only when used:** off by default; it starts the first time you open Controls (or after you turn it on in Settings), then stays on. Saves RAM/power for people who never pair.
- Fix the `AgentState` name clash between `agents.h` and `llm_service.h` (it blocked a merged build in the size experiment).
- Migration: devices on either 2.x edition keep NVS; the carousel (`scr`) is rebuilt with the new defaults only if it was never customized.

## 2. Screen order (decided with the user)

Order by what you use, then what you check, then setup:

```
Home → Agents → Controls → Phrases → Timer → Tasks → Agenda → Streak → Weather → Settings → Setup (QR) → More
```

- Agents and Controls appear only once they're useful: Agents after the first agent card arrives (or the Claude Code plugin is installed), Controls after Bluetooth is turned on. Until then they're in More, so a new user's carousel starts lean.
- **Settings** becomes a carousel screen (today it's only in More).
- More keeps the rest: Calendar, Stats, Focus, Brief (AI), Update, Tour.
- Everything stays reorderable from the web (Screens step).

## 3. AI chat and Notion: worth it?

| | Today | Verdict for 3.0 |
|---|---|---|
| **AI chat** (Agent screen, your OpenAI/Anthropic key) | Picks from canned prompts (no keyboard or mic); long answers on a 1.5" screen; needs a paid API key | **Reshape into "Daily brief"**: one call each morning that turns your calendar + tasks into 3 short lines ("3 meetings, the key one is at 11; start with X"), shown in the Morning Brief and on Home. Optional, set up under *Advanced* on the web. The free-form chat screen goes. |
| **Notion** (tasks from a Notion database in Agenda) | Useful only for Notion users; setup needs an integration token + sharing the database | **Advanced, hidden by default** in the web setup, with a 3-step helper. Priority goes to sources most people have: **Google Tasks / calendar to-dos (VTODO)** through the iCal link they already add. |
| Spotify, Firebase | Compiled out already | Stay out (remove the dead code from the repo). |

## 5. Launch criteria (ROADMAP Phase 1 exit)
- Someone new flashes and sets up Tasky in under 5 minutes, from a computer **and** from a phone only (watch two people do it; note every hesitation).
- A week of daily use without a reboot (log free heap at boot and hourly; no leak).
- Every flow tested on real hardware: C3 and C6, Mac and Windows (Controls), Claude Code approvals.
- Upgrading from 2.12 keeps settings; from 2.11 or older needs the one web update (already documented).
